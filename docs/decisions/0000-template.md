# 0000. Title of the decision

Ordered by issue #0.

Copy this file, replace the number with the number of the issue that decided
the thing, and keep all five sections. A file missing one of them is a note and
not a decision record.

## Question

What was being decided, written so that somebody who was not there can tell
which question this record answers and which it does not.

## Answer

The decision, in the present tense, stated as what holds rather than as what
was proposed.

## Reasons

Why this answer and not the others that were on the table. Name the ones that
were rejected and say what they cost, because a record that lists only the
winner cannot be argued with later.

## Ruled out

What the answer forbids. A decision that rules nothing out has not narrowed
anything and is a preference rather than a decision.

## Reopened when

The condition that makes this record worth arguing again. A measurement, an
arrival, or a change outside this repository. "When somebody feels differently"
is not a condition.
